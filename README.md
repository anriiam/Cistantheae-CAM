# Cistantheae-CAM

#### Anri Chomentowska and Lan Wei

Data, scripts, and outputs from Jose et al (2026): "Two putative instances of evolutionary loss of CAM photosynthesis within the plant clade Cistantheae."

### In this repository, you will find:

- Data frame and R script for analyzing titration data
- Data frame and R script for titratable acidity x SWC regression (Fig4_species_level_data.csv, Fig4.R)
- R script for species distribution models and RDS files from species distribution GLM outputs
