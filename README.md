# Cistantheae-CAM

#### Anri Chomentowska and Lan Wei

Data, scripts, and outputs from Jose et al (2026): "Two putative instances of evolutionary loss of CAM photosynthesis within the plant clade Cistantheae."

#### In this repository, you will find:

R script and data frame for analyzing titration data
  - Fig2_CAM_titration_analyses.R
  - Fig2_Titrations_CAM_Diversity.csv)

R script and data frame for species distribution models and RDS files from species distribution GLM outputs
  - Fig3_SDM
      - 2025_data_elev_bioclim.csv
      - bioclim_output.zip
      - Niche_GLM.R
      - RDS_files
          - by_species (12 .rds files for re-loading results)
          - comparisons (4 .rds files for re-loading results)

R script and data frame for titratable acidity x SWC regression
  - Fig4_SWC_deltaH.R
  - Fig4_species_level_data.csv)
